Wisp — Privacy Policy

Wisp is a personal desktop app that runs only on the user's own Windows computer.

What it accesses

With the user's permission, Wisp reads Google Calendar events, creates or edits events the user asks for, reads Gmail unread counts and labels, and sends email only when the user presses send.

Where data goes

Data from Google is shown inside the app and cached only on the same computer. Access tokens are encrypted with the operating system's secure storage. Nothing is sent to the developer or to any third party, and nothing is sold or used for advertising.

Removing access

Disconnect Google in Wisp settings, or revoke access at myaccount.google.com/permissions. Deleting Wisp's local data folder removes all stored data.
